# ChatWorker

一个 Vue 3 + Electron 的个人 AI 工作空间。Web 与桌面共用界面，支持主流模型 API、流式聊天、项目分组、本地会话记录和可检索的空间资料。

## 快速启动

开发与完整验证环境：Node.js 22.21.1+、npm。首次运行需要下载依赖；真实模型请求需要自己的 API Key。

```bash
npm ci
npm run dev
```

浏览器打开 http://127.0.0.1:5173 。没有 Key 也可使用明确标注的本地演示模式。

生产构建与本地运行：

```bash
npm run build
npm start
```

打开 http://127.0.0.1:4317 。只监听本机地址，不是公网部署方案。

桌面版：

```bash
npm run desktop
```

生成当前平台的应用产物：

```bash
npm run desktop:pack
```

产物位于 `release/`；macOS 生成 `ChatWorker-mac-arm64.zip`（Intel 为 x64），解压后得到应用。打包脚本先在临时目录签名，避免同步目录的 Finder 元数据干扰。macOS、Windows、Linux 的安装包目标已配置；本次验证平台为 macOS Apple Silicon，Windows/Linux 需要在对应平台验证。正式分发前还需平台签名与发布流程。

## 配置模型

打开「设置 → 模型服务」，选择供应商，填写 Base URL、API Key、模型 ID，再点「保存并使用」。多个模型 ID 用英文逗号分隔。可以选择：

- OpenAI：Responses 协议。
- Anthropic：原生 Messages 协议。
- Google Gemini：OpenAI 兼容协议。
- DeepSeek：OpenAI 兼容协议。
- 自定义服务：支持上述三种协议，可连接本机 HTTP 接口。

接口适配已实现并通过模拟流测试。真实账户权限、余额和模型是否可用需使用自己的 Key 进行测试；测试按钮会产生一条简短 API 请求。

DeepSeek 预设提供 `deepseek-flash` 与 `deepseek-v4-pro`。已有自定义模型列表保留，可在设置中点击预设追加。输入框旁的模型面板支持搜索，并为官方 DeepSeek 接口的已知模型分别保存默认/直接回答/思考，以及轻量、深入、充分三档强度；其他接口保持默认参数。模型 ID 与参数以[官方说明](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)为准，不保证账户已开通。

「测试已保存配置」可选择已保存的具体模型，收到首段正文或模型思考即确认连接并停止测试。错误留在设置页，区分上游 HTTP 状态、参数错误、余额不足和本机测试超时；连接成功不代表长对话或工具执行已经验收。

Web 模式的 Key 仅存服务端内存，重启后需重填；也可使用 `OPENAI_API_KEY`、`ANTHROPIC_API_KEY`、`GEMINI_API_KEY`、`DEEPSEEK_API_KEY` 环境变量。`.env` 不自动加载；可在构建后使用 `node --env-file=.env dist/apps/server/src/cli.js`。不要提交 `.env`。

桌面版在系统加密可用时，通过 Electron `safeStorage` 加密保存 Key；不可用时退回内存模式，设置页显示实际存储方式。

## 已实现

- 聊天与工作两种提示模式，Markdown 和代码块展示。
- 流式响应、停止生成、错误提示与部分结果保存。
- 项目创建、会话搜索、重命名、归档、恢复和删除。
- 文本/代码附件，每个最多 100 KB，每条最多 5 个。
- 会话 Markdown 导出、回复复制、实际活动记录。
- 可展开的执行过程、模型实际返回的思考内容与 token 用量（仅在接口返回时显示）。
- 模型服务设置、连接测试、系统指令及浅色/深色/系统主题。
- Web 与 Electron 共用前端、本地服务和模型适配层。
- SQLite 历史与稳定草稿；多窗口冲突比较、版本副本恢复和下载。
- 空间资料库：上传文本/PDF/DOCX、收集历史附件与回复、新建笔记、预览下载、收藏和回收站。
- 按需开启本地 RAG：检索相关片段交给当前模型，保留来源、行号与原文快照。
- 「关于 ChatWorker → 运行能力」显示服务版本、已支持的功能、保存方式与实际使用限制，可刷新查询。

工作模式当前是规划和文本协作，不执行终端命令，不读取未选择的本地文件，不自动修改项目代码。MCP、Agent 工具循环及多 Agent 属于后续阶段。

### 备份与迁移

新目录直接初始化 SQLite。已有 `state.json` 时，先关闭使用此目录的旧版 Web 和桌面服务，再离线升级：

```bash
npm run storage:migrate -- /absolute/path/to/data-directory
```

完成后重新启动服务；桌面版也可在启动提示中选择「备份并升级」。旧版本不认识新版目录锁，升级后也不要再用旧程序写此目录。升级保留原 JSON 和经过 SHA-256 校验的独立备份；中断后可重新运行并恢复迁移。数据库损坏、版本不兼容或升级后文件缺失时停止启动，不清空记录，也不自动回退旧 JSON。恢复步骤与限制见 [迁移文档](docs/adr/0002-sqlite-migration.md)。

已有 v1/v2/v3 SQLite 会在启动时先保留按 SHA-256 命名的原版本字节备份，再事务升级到 v4；资料库标识、历史和已保存草稿保留。详见 [稳定草稿](docs/adr/0003-stable-drafts.md)和[模型选项与执行记录](docs/adr/0004-model-options-and-execution.md)。空间存储见 [ADR-0005](docs/adr/0005-spaces-and-retrieval.md)。旧程序不能打开 v4 数据目录。

在「设置 → 数据与归档」导出 JSON 备份，或选择备份文件预览后导入（最大 20 MiB）。包含项目、消息、文本附件、活动及消息执行详情（含模型思考与本次引用快照），不包含 API Key、模型配置、草稿和空间资料库原文件/索引。导入添加独立副本，不覆盖现有数据；重复导入会产生重复副本。Web 与 Electron 可以通过备份迁移会话。旧版客户端可能忽略新增执行详情，迁移时请使用兼容新版。

### 空间与资料问答

1. 左侧进入「空间」，上传文件或新建笔记。支持 UTF-8 文本、Markdown、常见代码、文字型 PDF、DOCX。预览展示提取文字，可以下载原文件。
2. 「对话中的资料」集中查看历史附件；选择「保存到空间」后成为独立资料。助手回复下方也可保存。原会话删除后，已收集的副本仍保留。
3. 打开资料后选择「用这份资料提问」，或在聊天输入框上方开启「参考空间资料」。默认关闭；开启后，相关片段会发送给当前选定的模型服务。
4. 回答下方可查看本次提供给模型的片段、来源行号与原文快照；执行详情记录实际空间检索。收藏便于整理；关闭参考开关或移入回收站后，该资料不再参与检索。回收站支持恢复。

这版是本地词法 RAG（中英文分词与 BM25 排序），无需额外向量服务或 Key；并非向量语义检索，换词提问可能漏召回。单文件最多 5 MiB、提取文字 20 万字符、PDF 200 页；最多 200 份资料（含回收站）、原文件合计 100 MiB。每次最多提供 6 个片段。扫描件需先做 OCR，图片/表格布局不会原样重建，暂不支持 PPTX/XLSX。当前没有永久清空回收站、资料内容编辑或空间整体导出；重要原文件请自行保留，现有 JSON 会话备份不包含完整空间。具体限制见 [空间设计](docs/adr/0005-spaces-and-retrieval.md)。

### 项目管理

侧栏项目区的管理按钮或「设置 → 项目管理」可以编辑名称和说明。删除项目会保留所有会话（含归档）、消息和附件。在「会话详情 → 所属项目」可移动会话或改为独立会话。生成期间的相关操作会被阻止，以保持状态一致。

### 会话分支与重新生成

回复下的「从此继续」把该回复和之前的消息复制为独立会话。「重新生成（新分支）」保留原会话，在新分支中使用当前选定模型重新回答原问题，包含原附件，不带入之后的对话。真实模型可能产生 API 费用。若分支创建成功但模型请求尚未开始，可修正设置后点击「使用当前模型生成回复」。

### 输入草稿

未发送的文字与文本附件按会话分别保存，新会话按项目和聊天/工作模式区分。停止输入约 400 毫秒后保存到当前本机资料库。看到「草稿已保存到本机」后，刷新或服务更换端口仍能从同一资料库恢复；Web 和桌面默认使用不同资料目录，不是跨设备同步。

两个窗口同时编辑时，界面比较「本窗口版本」和「资料库已保存版本」。可以选择任一版本或下载两个版本；选择会保留被替换内容的副本，不自动合并。展开「可恢复的草稿副本」可以再次比较并恢复。发送前先确认草稿保存，服务接受消息后只清除相符版本，避免旧请求清掉新输入。

断线时保留窗口缓存并显示重试、下载入口；未确认保存的缓存仍受浏览器地址和容量限制，退出瞬间的写入不作持久化保证。当前地址可读到的旧版草稿作为副本提供显式恢复，不能自动读取其他端口的旧缓存。草稿及副本为本机明文，不包含在现有 JSON 会话备份中；下载的草稿 JSON 用于人工保留，尚无文件重新导入入口。细节见 [ADR-0003](docs/adr/0003-stable-drafts.md)。
