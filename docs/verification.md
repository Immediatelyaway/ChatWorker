- 真实供应商 API 尚未使用用户 Key 联调；协议模拟测试不是供应商账户可用性证明。
- 没有测试 Windows/Linux 桌面运行与安装包。
- 没有实现或测试终端执行、项目文件写入、MCP、后台 Agent。
- 当前服务中断时取消请求；没有持久任务恢复与消息幂等重放。
- macOS ARM64 应用压缩包已生成，解压后通过 codesign 深度验证，并实际打开了打包后的 ChatWorker 窗口。应用采用本地 ad-hoc 签名，尚未进行 Apple 公证。

## 本机复现

```bash
npm ci
npm test
npm run build
npm start
# 浏览器打开 http://127.0.0.1:4317

# 另一次运行使用桌面版
npm run desktop
```

开发版 Web 与桌面默认使用独立数据目录。不要同时使用同一目录测试，以免单文件存储产生竞争。

## 客户端草稿验证

17 项测试、类型检查和生产构建通过。新增测试覆盖文字与附件恢复、会话/项目/模式隔离、快照独立性、新会话草稿迁移、旧请求不能清空新草稿、容量不足的内存回退、损坏或未知版本不被读取操作覆盖，以及服务端拒绝请求不触发清除。

浏览器使用独立端口和临时数据验证：输入工作草稿，切到聊天模式为空；切回并刷新后原文恢复；发送后输入框清空；填写下一条草稿后切到新会话为空，切回原会话恢复下一条草稿。

草稿是按访问地址保存的客户端数据，不进入备份。Electron 随机端口导致跨退出重启恢复暂不保证，本轮未重打包桌面安装包。
