## 2026-10-22：SQLite 迁移与恢复（CW-003）

38 项自动测试全部通过；Vue/TypeScript 类型检查、Web 生产构建、服务端编译通过。以下是本轮新增或扩展的验收，前述 CW-002 的“仍保存 JSON”是历史状态，当前生产服务已经接入 SQLite。

- 显式升级无版本旧 JSON，保留项目、消息、附件顺序、归档、活动文字和 ID；验证原文件及 SHA-256 备份字节、stable storeId、重开后的新修改和中断消息只恢复一次。未选择升级时不创建迁移计划。
- 损坏 JSON、未来状态版本、未来数据库版本、损坏文件头和不支持的 WAL 文件头被拒绝且原字节不变；已激活数据库缺失时拒绝回退 JSON；迁移源变化或备份损坏时不激活新库。
- 在计划落盘、备份完成、事务导入中、事务提交后、切换前、切换后、激活完成七处实际 SIGKILL 子进程，随后恢复，不丢失原记录或重复导入。另在业务写事务中制造未提交磁盘页后 SIGKILL，验证 hot rollback journal 恢复到上一提交。
- 第二进程不能获得同一目录写入权，杀死持有者后可以重开；正常服务重复 close、生成期间关闭、端口被占用导致启动失败后重试均释放连接和目录锁。
- 用 SQL 触发器模拟项目写入、初始消息保存、终态保存失败，验证事务回滚、内存保持已提交状态、不误发 done、活动请求释放；八个并发项目修改均保留。worker 等待数据库锁时，能力 HTTP 查询仍可响应。
- 凭据保存失败后，旧 Key 和预设环境变量 Key 都不会被发送到新地址。前端保存失败测试确认保留可见回复、具体错误提示，并阻止对未保存消息建立分支。

`npm run verify:storage` 在 Node 22.21.1 / SQLite 3.50.4、Electron 44.9.0 主进程 / Node 24.22.0 / SQLite 3.53.4、以及真实 electron-builder ASAR 打包测试应用中均通过。除原驱动事务检查外，三个环境均调用生产 Storage 和独立 worker 完成旧 JSON 升级、第二实例拒绝、修改、重开、固定 storeId 和旧文件保留。Node 的 WAL 仍被版本保护拒绝；Electron 驱动试验的 DELETE/WAL 均通过，生产业务库固定 DELETE。

浏览器验收使用独立临时目录、随机端口和生产构建：实际运行编译后的离线迁移入口，打开升级前会话确认正文保留；“运行能力”显示本机数据库保存说明；注入终态保存失败后，完整演示回复仍可见，出现“尚未保存，请先复制”提示，复制按钮保留，分支与重新生成按钮禁用。测试页和临时服务已关闭，未迁移用户现有历史。

打包验证仍是最小存储测试应用，不是完整 ChatWorker 安装包；macOS sandbox extension 提示不影响检查通过，不据此宣称窗口或沙箱授权验收。桌面升级对话框没有做完整人工操作验收，Windows/Linux、真实断电、真实磁盘耗尽、硬件故障、大数据量性能和付费模型请求未验证。迁移备份仅覆盖升级时快照，不是持续备份；当前仍全量重写关系记录，没有 token 检查点、事件重放或稳定草稿。使用与恢复步骤见 [ADR-0002](adr/0002-sqlite-migration.md)。

## 2026-10-22：稳定草稿与多窗口冲突（CW-004）

50 项自动化测试全部通过，Vue/TypeScript 类型检查、Web 生产构建与服务端编译通过。新增服务端草稿及客户端同步状态测试。此前“草稿仅按 origin 保存”和“尚无稳定草稿”属于历史状态，现已接入资料库草稿 v2。

- 两个并发 HTTP 写入只允许一个版本成功，另一份非空输入持久保存为恢复副本；旧版本清空/复活被拒绝，错误 storeId 和无效内容被拒绝。关闭服务并更换端口后，同一 storeId 的文字、附件和副本保留。
- 普通历史/设置修改不覆盖草稿；删除项目清空所属新会话草稿、增加版本并拒绝旧请求；其他位置保持。显式副本按内容去重，选择覆盖可在同一事务保留前一稿。
- 用 SQL 触发器模拟草稿更新与副本写入失败，检查当前正文、版本和副本整笔回滚；故障解除后继续保存成功。这不等于真实磁盘耗尽试验。
- v1 SQLite 加表升级保留历史与 storeId；备份文件名和字节与升级前 SHA-256 完全相符。制造表冲突导致迁移失败，确认 user_version 仍为 1，备份保留。
- 客户端覆盖两窗口冲突选择、旧回执不能清新稿、保存中继续输入、旧读取成功或失败都不能覆盖后来保存的内容与状态、保存响应丢失后与另一窗口竞争、各窗口缓存隔离、不同资料库隔离、v1 显式比较、转存失败保留源稿、容量不足仍能服务保存、比较期间切换副本保留新编辑。
