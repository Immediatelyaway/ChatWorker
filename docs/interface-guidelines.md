# ChatWorker 界面规范与检查记录

更新：2026-11-03。对应共享 Vue Web / Electron 界面，不改变模型、资料或存储接口。

## 参考范围

以用户提供的 Codex / ChatGPT Work 截图为布局参考，统一窄导航、会话侧栏、中央输入区、资料列表、设置和浮层。当前工具禁止直接操控 `com.openai.codex` 应用，因此未完成实时逐像素对照；保留 ChatWorker 名称与标记，不添加截图中尚未实现的功能入口。

## 视觉规则

| 项目     | 约定                                                                  |
| -------- | --------------------------------------------------------------------- |
| 色彩     | 中性灰画布、白色内容面、浅灰侧栏；蓝色用于操作和焦点                  |
| 深色     | 中性黑灰层次；正文、分隔线、禁用态和控件使用同一套变量                |
| 字体     | 系统字体；正文 15px，导航/输入 14–16px，辅助信息 11–13px              |
| 阅读宽度 | 对话/首页 780px；设置最多 860px；空间列表随可用区域展开               |
| 圆角     | 控件 10px，卡片 18px，弹窗 22px，输入框 26px；模型/模式选择采用胶囊形 |
| 阴影     | 输入框轻阴影；菜单和模态浮层使用更高一层阴影，不给每个列表行添加阴影  |
| 动效     | 小范围颜色、阴影及弹层入场；尊重 prefers-reduced-motion               |
| 焦点     | 键盘操作保留可见焦点；输入区通过容器反馈焦点                          |

样式入口按基础布局、控件与模型细节、空间组件、共享外观层加载。`styles/workbench.css` 集中管理本轮视觉变量和跨页面密度、主题、断点；不把模型行为写进样式。修复了控件重置中的 `border-radius: 0` 对已有组件圆角的覆盖，以及 select 的背景简写抹去下拉箭头的问题。

## 页面与状态

- **首页**：简洁标题、居中输入框、项目/附件工具条、按需开启的空间参考、紧凑建议入口。空白且已保存的草稿不再显示冗余状态；非空、保存中、失败或冲突仍可见。
- **对话**：正文、代码块、表格、用户气泡、执行详情、引用卡片和消息操作统一字号与灰阶；横向长表格在正文内部滚动。
- **导航**：侧栏按所在页面显示 ChatWorker / 设置 / 空间；当前项保持可辨识，截断会话可通过标题提示查看全名。
- **设置**：模型服务、常规、外观、项目管理、数据与归档、关于共用表单规范；切换分类回到页面顶部。备份说明明确空间原文件和草稿不在当前会话备份中。
- **空间**：上传、历史资料、收藏、回收站共用列表；预览和笔记共用浮层规范；参考开关有自定义开关外观并保留原生复选框语义。
- **浮层**：菜单支持点击外部关闭；搜索、重命名、项目、笔记和原文预览支持首个控件聚焦、Tab/Shift+Tab 循环、Escape 关闭与焦点归还。处理中仍遵守组件的关闭限制。
- **手机/平板**：900px 以下提供抽屉侧栏；设置分类和模型服务标签可横向滚动；620px 以下去除外框，输入字号为 16px。抽屉仅打开时启用模态焦点管理，切换目标或回到宽屏关闭。

统一焦点逻辑放在 `directives/dialog.ts`。只对当前最上层弹窗处理键盘；组件提供关闭回调，指令不自行提交表单或修改业务数据。模型选择是非模态面板，继续使用其原有定位、搜索聚焦、外部点击和 Escape 行为。

## 本轮验证

- Vue/TypeScript、Web 构建与服务端编译通过；现有 61 项自动测试通过。
- 使用合成会话、项目和文档检查首页、聊天正文/代码/表格、会话详情、空间预览、六个设置分类、个人菜单、搜索结果与空状态、创建项目弹窗。
- 浅色与深色、390px 窄屏与默认桌面宽度实测；检查窄屏导航、分类入口、模型面板和滑块。另在 800px 视口读取模型面板边界，未越出窗口。
- 项目弹窗和手机抽屉验证 Shift+Tab 回到最后可用控件；Escape 关闭并返回触发按钮。搜索验证自动聚焦及空结果。
- 模型面板检查使用隔离服务的无效占位 Key，仅用于显示配置，不执行连接测试或真实模型请求。
- 用户开始在第一份预览输入后立即停止操作该窗口并保留服务；后续检查改用第二份隔离资料。用户原有安装版、凭据和数据目录未被迁移或替换。
