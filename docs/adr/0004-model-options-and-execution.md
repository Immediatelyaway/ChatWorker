# ADR-0004：按模型配置、连接诊断与执行记录

日期：2026-10-22。状态：已实现；不代表 CW-005～010 的 Run、工具和恢复能力完成。

## 背景

模型 ID、思考开关、强度及流字段随供应商变化，不能把一个全局滑块直接映射到所有接口。旧连接测试只等待正文，可能忽略先返回的思考；同时把所有异常都返回为本机 HTTP 400，掩盖了超时与上游状态的区别。

本次报告的历史 400 未复现：针对现有保存配置的一次测试成功。以下是对已确认代码缺陷的修复，不是对该次失败原因的推定。

## 决定

1. `packages/shared/model-catalog.ts` 集中模型展示名、已知能力和思考档位。仅对官方 `api.deepseek.com` 的兼容协议与已知模型发送专有选项；现有模型列表不自动替换。
2. `Provider.modelOptions[modelId]` 保存 `thinking` 与 `effort`，发送时快照到 `Message.execution.options`。关闭思考时省略强度；参数未知的接口保持原有请求。
3. 模型适配器输出明确类型事件。当前 Chat Completions 的 `reasoning_content` 作为「模型返回的思考」，单独显示、限长、保存，不冒充工具执行，不回填下一轮文本上下文。
4. 连接测试收到首段正文或思考即成功并取消上游流；仅收到 HTTP 响应头不成功。20 秒超时返回 504；上游错误返回本机 502，并附独立的上游状态和固定分类。错误体限读 8 KiB，参数名允许列表过滤，不显示原始错误体。
5. 可折叠时间线记录本次真实上下文准备、连接、思考、回答、结束、错误与停止；用量仅显示接口实际提供的数字，不估算价格。收到工具调用时显示「未执行」并失败退出，当前没有读取文件、搜索资料或执行命令的动作。
6. Vue 组件独立为 `ModelPicker` 和 `ExecutionDetails`，视觉细节放在 `styles/refinements.css`。弹层在页面顶层定位，保留搜索、键盘、窄屏、焦点和减少动画语义。

## 存储及兼容性

- SQLite 升至 v3，增加 `providers.model_options_json` 和 `messages.execution_json`。新建库与 ALTER 升级后的物理列顺序不同，写入必须显式列名。
- v1/v2 在独占目录锁与数据库事务下生成 `state.sqlite.backup-v<旧版本>-<SHA256>`，验证原字节，再升级；v1 还会创建草稿表。失败回滚结构与版本号，保留原备份。
- 草稿版本 2、能力版本 3、状态与 JSON 会话备份版本 1 不变；新增可选字段不会使旧会话无效。新版备份包含消息 execution（也包含模型思考），不包含供应商模型选项、Key 或草稿。旧客户端会忽略未知字段，因此往返旧客户端可能丢失执行详情。
- 执行正文与记录仍在终态事务保存，不是逐事件持久日志。停止可保留已接收内容；进程异常退出可能丢失最后一次未保存增量。运行重放、幂等接受和工具恢复继续按 CW-005～010 实现。
- 思考和执行详情与消息一样是本机明文，导出会话 JSON 时随消息包含；Markdown 导出与回复复制仍针对正文。

## 验证与后续

覆盖参数映射、思考优先的连接测试、上游状态分类、错误不回显内容、工具拒绝、执行详情备份与重开、v2 升级与失败回滚。浏览器验证模型独立配置、搜索、键盘、详情和窄屏深色主题。具体证据见 [验证记录](../verification.md)。

继续完善时，需要为每个供应商建立独立能力表和实际账户验收，补齐 Responses/消息协议的思考摘要及完整用量，并在持久 Run、事件恢复和权限成立后接入工具。不要只根据模型输出文字生成“已搜索”“已运行命令”等执行记录。
